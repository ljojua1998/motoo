# motoo

მართვის მოწმობის **A კატეგორიის** (მოტოციკლი) თეორიული გამოცდის სასწავლო აპი — 738 ბილეთი, ერთ დღეში გასავლელად დალაგებული.

## რა არის შიგნით

- **738 ბილეთი** პასუხებით, სწორი პასუხით და კანონის განმარტებით
- **360 ბილეთის სურათი** + **99 საგზაო ნიშანი** — ყველაფერი ლოკალურად, ოფლაინ მუშაობს
- 6 სასწავლო ბლოკი შიგთავსის მიხედვით დაჯგუფებული: ნიშნები → შუქნიშანი/გზაჯვარედინი → მოტო-სპეციფიკა → სამედიცინო → ეკო/უსაფრთხოება → დანარჩენი წესები
- ბილეთი „ნასწავლია" ზედიზედ 2 სწორი პასუხის შემდეგ; შეცდომა იმავე სესიაში ბრუნდება
- ციფრების ცნობარი, ნიშნების კატალოგი ძებნით, გამოცდის სიმულაცია (30 კითხვა / 30 წუთი)
- პროგრესი `localStorage`-ში — ბექენდი არ სჭირდება

## სტეკი

სუფთა სტატიკა — HTML + CSS + vanilla JS. არც ფრეიმვორკი, არც build-step, არც დამოკიდებულებები.

| ფაილი | რა არის |
|---|---|
| `index.html` | მთელი აპი — მარკაპი, სტილები, ლოგიკა |
| `data.js` | ბილეთების, პასუხებისა და ნიშნების მონაცემები |
| `img/`, `signs/` | ბილეთების სურათები და ნიშნების SVG-ები |
| `serve.py` | ლოკალური სერვერი (სწორი MIME ტიპებით `.webp`-ისთვის) |

## ლოკალურად გაშვება

```bash
python serve.py      # http://127.0.0.1:8777/
```

Windows-ზე: `გაშვება.bat`

## დეპლოი

სტატიკური ჰოსტინგი საკმარისია — build-ი არ არის. `vercel.json` უკვე შეიცავს სურათების კეშირების ჰედერებს.
